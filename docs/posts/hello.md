# Hello VuePress

欢迎来到 VuePress 的世界!

## 什么是 VuePress?

VuePress 是一个由 Vue 驱动的静态网站生成器,由尤雨溪创建。它最初是为编写技术文档而设计的,但同样适合搭建博客。

## VuePress 的主要特点

1. **Markdown 优先**:你可以直接使用 Markdown 来编写内容,同时享受 Vue 的能力。
2. **内置搜索**:默认主题自带标题搜索,无需额外配置。
3. **Vue 组件支持**:在 Markdown 中可以直接使用 Vue 组件,实现丰富的交互。
4. **SEO 友好**:每个页面预渲染为静态 HTML,对搜索引擎友好。
5. **插件系统**:强大的插件 API,可扩展各类功能。
6. **PWA 支持**:开箱即用的 PWA 配置。

## 写作示例

你可以像写普通 Markdown 一样撰写文章:

```js
export default {
  name: "MyComponent",
  data() {
    return { msg: "Hello VuePress" };
  }
};
```

开始你的 VuePress 写作之旅吧!
